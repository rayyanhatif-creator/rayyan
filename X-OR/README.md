# Rayyan — مشروع X:OR

هذا المجلد مخصص للعبة **خارج المنطق — X:OR**، بشكل مستقل عن ملفات مشروع حديقة طيور الريان الموجودة في جذر المستودع.

## النموذج الحالي
- نموذج أولي تفاعلي يعمل في المتصفح.
- لغز افتتاحي عن الجاذبية ولوحة الضغط.
- واجهة عربية تدعم الجوال.
- اللعبة هنا تجربة ثنائية الأبعاد للفكرة، وليست بعدُ لعبة ثلاثية الأبعاد مكتملة.

## التشغيل
افتح `index.html` في المتصفح، أو انشر المجلد عبر GitHub Pages بعد ضبط إعدادات النشر المناسبة.
